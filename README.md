# 🌌 Lucid AI - Just another Gemini AI

LucidAI is a powerful mobile chat application powered by **Gemini 1.5 Flash**, designed to bring lightning-fast conversations, intelligent insights, and natural language magic straight to your hands. Think ChatGPT — but personalized, lightweight. 
---

## 🚀 Features

- ⚡ **Powered by Gemini 1.5 Flash** – Ultra-fast, high-quality responses from Google's cutting-edge LLM.
- 💬 **Smooth Chat UI** – Intuitive and clean interface built with React Native + NativeWind.
- 🌙 **Dark Mode Ready** – Night owls rejoice!
- 💾 **Conversation History** – Keep track of your thoughts, ideas, and discoveries.
- 📱 **Mobile Optimized** – Built natively for Android/iOS devices.
- 🔐 **Secure Input Handling** – Your data, your control.

---

## 🛠 Tech Stack

| Tech | Description |
|------|-------------|
| ⚛️ React Native | Core framework for cross-platform mobile development |
| 🌬 NativeWind | Utility-first styling using Tailwind syntax |
| 🧠 Gemini 1.5 Flash | Google’s blazing-fast large language model |
| 🔗 Axios | Handles API calls to the Gemini backend |
